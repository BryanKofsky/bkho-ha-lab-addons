# BKHO HA Lab Add-ons

LAB ONLY Home Assistant add-on repository for BKHO V-001 remote repository distribution proof.

This repository is not the production BK Home Ops distribution repository. It contains only the minimum public surface needed to prove that Home Assistant can discover, install, and start a lab proof add-on through the normal add-on repository flow.

Substantive BK Home Ops provisioning, orchestration, customer management, support access, registry, journal, Cloudflare, Tailscale, and production bootstrap logic intentionally remain private.
